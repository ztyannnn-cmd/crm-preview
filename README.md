# Solbridge CRM 演示原型

本机地址：http://127.0.0.1:8765/

- `index.html`：共用样式、固定顶部导航及页面容器。
- `app.mjs`：三板块界面、共用达人卡片及详情、模拟账号切换。
- `model.mjs`：用户、达人、campaign、成员及合作记录；原型可见性与状态流转规则。
- `model.test.mjs`：数据范围、成员分配、重复提报、生命周期和迁移验证。

运行验证：`node --test crm-preview/model.test.mjs`

浏览器存储从 `solbridge-crm-100-v1` 迁移到 `solbridge-crm-projects-v2`。保留旧存储；原达人报价、历史回价、最终金额和发布信息迁移到合作记录。请勿通过删除存储来升级数据。

所有达人卡片通过同一 `card()` 渲染，项目与提报跟进共用合作数据和 `coopDetail()`，后续 UI 调整应修改共用组件。总库不公开其他项目的报价和执行信息。

默认 PM 小王，页面右上角可切换 PM 小陈、运营 A/B/C。这是本地演示权限，不是服务端安全隔离。账户切换保留业务数据并关闭详情、清空页面筛选；未接入真实登录、飞书通知或共享数据库。

## 2026-09-24 更新

- 增加超级管理员模拟账号，查看所有数据并可执行现有 PM / 运营操作。
- 提报跟进改为订单表；campaign 内保留达人卡片，同一达人不同项目的合作信息独立。
- PM / 超管可增减运营；有订单的成员暂不可移除，交接规则待定。
- 首页及 campaign 内增加看板；人数统计口径待定，暂展示说明。
- 新增客户确认价格，Margin 暂用客户确认价格减最终达人报价；缺失价格不按零计算。旧数据不推测客户价格。
- 单独录入仅达人 ID、主页链接、邮箱必填，平台可从主页链接识别，未知数据留空。
- 批量导入与 Excel 模板仍为后续功能，本次未接入。

启动预览（在项目根目录）：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory crm-preview
```

预览依赖本机服务持续运行；停服或电脑重启后需重新启动。


## 2026-10-07 全界面优化

- 三个模块共用项目页设计规范，保留顶部导航和蓝色配色，删除旧的行内样式。
- 默认打开提报跟进的“待我处理”；提供等待他人、全部订单、阶段导航和实时计数。
- 跟进页及项目内均可直接处理订单；PM、运营和超管的按钮由同一权限函数生成。
- 概览统计待我处理、议价中、已确认合作以及价格齐全订单的 Margin。已确认合作含补信息至已验收。
- 订单注明报价来源，更新时间使用业务操作时间；旧数据无操作时间则明确显示提报时间。
- 新增达人区分必填与选填，重复时可查看已有达人；提报成功可直接查看项目订单。
- 保存异常会回滚当前内存修改，保留输入供重试。关闭抽屉恢复列表位置及焦点；窄屏支持全宽抽屉、两行导航和表格内部滚动。
- 保留原存储键与 version 2，不重置旧数据。脚本、样片、结算、冷名单及独立飞书工具不在本次改动范围。

验证：`node --test crm-preview/model.test.mjs`（11 项）；浏览器检查 PM/运营/超管可见范围、直接处理表单、项目概览、搜索空态、重复达人提示及桌面/窄屏布局。
