# CRM 统一设计规范

三个页面共用 tokens.css、projects.css 和 header.css。`.ds-projects` 是沿用的全局样式作用域，现在覆盖整个 CRM，不再按页面切换。

- tokens.css：颜色、间距、字级、圆角和达人卡片列定义。
- components.mjs：按钮、页面标题、统计卡、筛选栏和数据列表。
- projects.css：共享页面、达人卡片、阶段导航、订单表、表单及抽屉样式。
- header.css：固定顶部导航和窄屏两行导航。
- followup.css：提报跟进页的处理范围、阶段与筛选层级、结果工具栏、表格下一步入口和空状态；使用 `.followup-page` 作用域，复用已有令牌，不覆盖详情抽屉布局。

常规页面顺序：标题与操作 → 概览 → 筛选 → 列表。提报跟进使用紧凑筛选与列表布局，发起提报并入筛选首行，默认待我处理；达人管理使用共用多平台资源表，项目详情保留达人卡片。窄屏仅数据容器横向滚动，抽屉全宽。

页面不新增行内样式。状态颜色仅表达业务状态，待办使用蓝色，不使用红色逾期提示。没有实现的功能不显示按钮。

业务权限、阶段、待办和统计统一来自 model.mjs；所有详情入口共用 coopDetail 与 operation，避免页面之间的业务分叉。

## 字号与抽屉（当前规则）

- 全局字号上限 24px（CSS 尺寸，不限制浏览器缩放）。页面标题 24px，抽屉标题 18px，区块标题 16px，正文/表单 14px，辅助文字 12px。统一使用 tokens.css 的字体令牌。
- drawer.css 是抽屉布局的唯一来源：CRM 桌面抽屉 640px，700px 以下全屏；新增达人等弹窗沿用独立尺寸。固定头部、单一内容滚动区，子区块不压缩，进度条自动换行。不要在 index.html 或 projects.css 追加同名抽屉布局覆盖。
- 本次只整理视觉样式，不修改业务数据或审批权限。
